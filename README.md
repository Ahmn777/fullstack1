# React + TypeScript + Backend API — контрольная точка

Готовый учебный проект для первой темы курса: соединение Frontend и Backend.

## Что здесь есть

- React + TypeScript + Vite
- Backend API на Node.js + Express
- `.env` на фронтенде с адресом API
- Публичный запрос: `/api/public`
- Авторизация: `/api/login`
- Защищённый запрос: `/api/private`
- Кнопки в интерфейсе для проверки всей цепочки Frontend → API → ответ сервера

## Запуск

Нужен Node.js 18+.

### 1. Backend

Откройте терминал в папке `backend`:

```bash
npm install
npm run dev
```

Backend запустится на:

`http://localhost:4000`

### 2. Frontend

В другом терминале откройте папку `frontend`:

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite, обычно:

`http://localhost:5173`

## Что проверить

1. Нажмите **Публичные данные** — должен прийти ответ от сервера.
2. Нажмите **Войти** — сервер вернёт токен.
3. Нажмите **Защищённые данные** — запрос отправится с токеном и вернёт закрытые данные.

Это учебный пример. JWT здесь имитируется простым токеном, чтобы сосредоточиться именно на связке Frontend ↔ Backend.
